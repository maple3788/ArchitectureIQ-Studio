# 按题匹配 KB 并自动作答

日期：2026-10-10

## 目标与已确认需求

用户希望系统读懂当前题目，自动匹配相关 KB，并把相关知识交给模型作答。用户已明确选择自动作答，而非仅展示推荐结果。

成功标准：选择现有题库中的一道题和一个模型后，可以预览推荐 KB、实际命中的知识及匹配依据，启动一次可追溯的 RAG 作答，并看到真实模型输出。无需逐个手动查看、挑选 KB。

“最佳 KB”在本功能中指当前检索策略下相关性和适用性排名最高的可用快照，不代表已经证明可以取得最高答题正确率。当前本地知识目录为空；空目录处理必须可用，不能用模拟知识填充生产页面。

## 方案比较与建议

1. **推荐：结构化适用条件过滤 + 文本检索排序。** 复用现有知识适用范围和经验来源校验，使用公开题面、模型结构、数据条件和知识文本进行确定性排名。只需要一次模型作答调用，沿用现有自托管 GLM 或 API 配置，匹配阶段不需要模型服务。
2. **结构化过滤 + 向量检索。** 可增加语义相似度信号，但需要明确 embedding 模型、服务、版本及索引生命周期。作为后续独立扩展，第一版不引入这些配置。
3. **结构化过滤 + 模型重排。** 模型比较少量候选知识后再作答，增加一次真实模型调用、预算和收据管理。第一版保留可扩展检索策略接口，但不实现此方案。

第一版采用方案 1。它是检索增强作答，页面如实显示使用的检索策略，不宣称已实现向量语义检索。

## 用户流程与界面

新增侧栏「RAG 作答」入口，题目详情提供「用这道题进行 RAG 作答」入口，将当前题目的目录 key 带入页面。

页面顺序为：题目与模型选择 → KB 匹配预览 → 启动作答 → 回答与来源。

- 复用题目选择器与公开题面阅读器；第一版每次选择一道题、一个模型。
- 默认在现有只读知识目录内搜索，展示最多 3 个候选 KB。每个候选显示名称、版本、知识类型、命中条目、验证状态和具体匹配依据。
- 自动选排名第一的 KB，从该快照提取最多 8 条合格知识。条数可设置为 1–12；预算不足时按顺序省略整条知识。
- 模型实际输入只包含当前公开题面及最终选中的知识条目，不包含候选快照的全部内容。
- 同时展示预览将带入的确切知识。修改题目、模型或条数后，旧预览失效，需要重新预览。
- 作答输出显示回答、解释及本次实际提供的知识来源。来源面板区分「检索时提供」和「模型返回的引用」；不推断模型一定使用了所有条目。
- RAG 是一次作答，不执行知识发现、训练、经验提炼或 KB 更新。
- 本地允许匹配预览；真实调用遵守执行服务器限制，禁用启动时显示现有的执行环境提示。

## 检索数据与准入

输入题目必须通过 Catalog 按 key 读取，检索查询使用其公开字段白名单：题干、family、候选方案公开结构和数据/训练条件。身份字段只用于来源排除和溯源，不作为相关性加分信号。

知识候选来自 `knowledge_inventory`。保持其完整性验证、同内容快照合并和来源记录；坏来源不进入候选，警告保留。请求方不能直接提交任意快照、路径或知识正文。

正式知识：

- 仅 `replicated_in_scope` 且 `enabled=true` 的规则可用于模型输入。
- 复用 canonical KB 引擎现有规则匹配和已验证适用范围判断，确认其适用于本题候选方案。
- 相关性排名处理全部合格记录，不能在排名前先按 ID 截断到 12 条。
- 仅返回 Solver 已有知识载荷允许的字段：id、revision、text、rule、status 和 validated_scope；不带证据账本、训练结果或私有反馈。
- 历史导入、禁用和未验证正式主张不进入自动作答。

学习经验：

- 仅检索来源可核验、状态为 active 的经验；沿用经验快照及封存案例校验。
- 只检索当前 family 的经验。任何来源案例与当前题目的非空 id、dataset_id、lineage_id 或 pair_id 相同时，排除该案例及引用它的经验。
- 模型输入仅包含经验文本、条件、例外、条目版本和来源标识；不包含完整案例、正确答案或原始反馈。
- 始终标注「经验，尚未独立验证」，不能提升为已验证知识。

正式知识的文本及经验文本作为参考材料放入现有受约束的 Solver 载荷，不允许知识条目授予工具或改变系统指令。

## 排序与可解释性

实现版本化、确定性的 `public_features_text_v1` 策略。

- 分词使用小写英文/数字标识符和中文相邻双字，避免依赖外部分词或模型服务。
- 对合格知识文本与结构化条件形成文本索引，以 BM25 提供文本相关性信号。
- 排序优先级依次为：适用于当前题目的已验证正式规则、明确公开条件吻合程度、文本相关性；稳定的内容标识用于最终打破并列。
- 经验需要具有公开条件或文本相关性命中；不能仅因快照较新、内容较多或与当前题目共享身份就获选。
- 每个 KB 用其中最高排名的合格条目确定排名；并列时比较最多 3 条不同的相关条目，再按稳定标识排序。
- 同一来源知识的相同版本及内容跨快照重复出现时，不在结果或模型载荷里重复计数。
- 每个命中返回具体原因，例如规则适用于哪些候选方案、相同题型、匹配的数据条件或文本词项。检索分数不是正确率或概率。
- 预算省略后至少需要一条相关知识；不得将本次零知识调用标成 RAG 成功。

索引为可重建的运行时缓存，身份包含候选目录内容指纹和策略版本；不得提交到 Git。预览与实际调用使用同一检索函数、同一已冻结结果。

## 后端接口与模块边界

新增 Studio 检索模块，负责公共查询生成、候选准入、去重、排名、预算裁剪及匹配说明。依赖现有 Catalog、知识目录及 KB 校验；不修改科学方法的检索策略。

新增 `POST /api/studio/rag/preview`：

- 输入：question_key、model_id、knowledge_limit（默认 8）。
- 校验题目、启用模型、模型参数和知识目录；不发送模型请求。
- 返回排名前 3 的 KB 摘要、实际选中的知识载荷、遗漏/排除统计、请求与保守上下文预算、目录与配置指纹，以及 sent=false。
- 返回可用于启动校验的 preview_hash，绑定题目、模型版本、检索策略、预算设置和候选目录内容。

新增 `POST /api/studio/rag/runs`：

- 接收上述选择及 preview_hash，支持现有 Idempotency-Key 约定。
- 服务端重新解析和核验来源；目录、题目、模型或匹配结果与预览不一致时返回 409，要求刷新预览。
- 执行环境未授权时拒绝创建真实调用任务。
- 冻结公开题面、模型服务身份/版本和参数、检索策略、候选目录指纹、选中 KB 版本、知识载荷、预算及匹配说明。

在 JobStore 中增加独立 kind=rag，在现有 worker 中分派 RAG 执行器。复用模型配置、私有凭据读取及脱敏、Solver Prompt/回答校验、调用收据、幂等管理、运行列表和 SSE。真实调用限制沿用现有执行主机检查。

新任务支持自托管与 API 模型。API 返回模型别名时记录实际返回身份，并标注权重身份未验证；不能借此改变科学研究方法的限制。

## 执行与持久化

执行阶段为 input → retrieval → solver → answer_commit → complete。

- 所有阶段由持久化事件驱动，界面不模拟模型文本。
- 匹配结果在 Solver 调用之前保存，实际传入条目必须与冻结结果相同。
- 真实模型调用前保存 reservation，完成后封存原始响应收据；复用已有不确定调用处理，禁止不确定状态下自动重复调用。
- 保存回答及匹配来源，作为运行结果供后续查看。模型引用只能解析为提供过的知识条目标识；未知引用不显示为可信来源。
- 此模式不读取或展示当前题目的私有 GT，也不执行评分。后续若增加效果评测，需要单独设计答案提交后揭示反馈的流程。
- 不修改既有草稿、研究运行、配对协议、历史哈希或封存记录。

## 边界与错误处理

- 空知识目录：展示「暂无可匹配 KB」，提供前往知识库/学习流程的入口，禁用 RAG 启动。
- 有 KB 但无合格命中：说明无适用知识，显示排除统计；不自动进行无 KB 作答。
- 所有命中均因上下文预算被省略：明确预算错误；建议减少条数或选择更大上下文模型，不截断题目。
- 坏来源或不合格知识：记录排除原因，允许其他合格来源继续匹配。
- 当前题目或知识版本变化：预览失效，不静默替换版本。
- 模型不可用、调用失败或中断：使用现有失败/不确定状态与收据提示，保留原匹配记录。
- 模型返回无效回答：记录真实响应并报告校验失败，不生成替代回答。

## 验证标准

使用本仓库准确的 Python 解释器，并先确认 import provenance。

后端 mocked 测试覆盖：相关命中与无命中、已验证规则适用范围、经验来源排除、停用/历史知识排除、稳定并列排名、跨快照去重、预算省略、目录变化导致 409、幂等创建、实际输入等于预览、API 凭据脱敏与模型身份、失败/不确定调用收据。恶意私有反馈字段必须不能进入查询或 Solver 载荷。

前端测试覆盖：当前题目带入、匹配预览、证据等级、空目录/无命中、配置变化使预览失效、禁用本地真实调用、真实 SSE 文本及来源面板。构建必须通过。现有科学/配对及模型配置相关回归测试按变更影响执行。

任何真实 GLM/API 冒烟调用只能在私有配置指定的授权 Linux 服务器运行；本地仅做预览、UI 构建和 mocked 测试。若未执行真实调用，完成报告明确说明。

## 第一版范围

包含现有题库单题、现有 KB/经验目录、自动选取一个 KB 的相关条目、一次真实模型作答、预览和来源溯源。

不包含自由文本题目导入、多 KB 混合作答、向量服务配置、模型重排、训练、生成新知识、自动反馈学习和独立效果评测。后续可基于版本化检索策略接口扩展。
